# Safease — open-source components

Source code of the open-source libraries used by the video player in **Safease**
(Android app by Safease Apps), offered under their licences.

This repository contains **only third-party open-source code** — not the Safease app.

| Library | Version | Licence |
|---|---|---|
| FFmpeg | 6.0 | LGPL v3 |
| mpv (libmpv) | commit 78d4374 | LGPL v2.1 or later |
| GNU FriBidi | 1.0.12 | LGPL v2.1 or later |
| libmpv-android-video-build (build scripts + patches) | v1.1.7 | MIT |

Download them from **Releases → libmpv-v1.1.7**. Each release's README.txt explains
how the libraries were built.
